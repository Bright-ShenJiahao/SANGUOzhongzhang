# 术语（关键词）
核心机制：
力竭＝内力耗尽进入的状态，部分内功在力竭时回气加速或威力变化
发劲＝消耗内力打出的强化攻击；“发劲消耗”指内力开销，“发劲伤害/威力”指其伤害加成；内力不足或力竭时无法发劲
周天循环＝角色按已装备的外功依次轮转出招，走完一圈为一个“周天循环”；许多增益与叠层以“本周天”为界，周天结束即清零或重置
护体＝受击时消耗内力抵挡部分伤害；挡下越多消耗越多；“护体强度”提升单次抵挡量；“护体触发”指成功挡下一次
波次＝一局从第1波打到第20波，击败终局首领即通关；无尽模式从21波继续；每波结束先“调息”再进入整备
蓄势＝同一周天内，同门派外功相邻出招会蓄势：第2/3/4门（头尾衔接）分别获得递增威力加成（约+15/+30/+50%）；“门派外功威力”加成被蓄势放大
