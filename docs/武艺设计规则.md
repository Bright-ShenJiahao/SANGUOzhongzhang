# 武艺设计规则（11/14 定，所有兵器照此做，避免返工）

参考：docs/群侠传图鉴参考.md（只参考结构，不照搬名字和效果）

## 已定规则
1. **强弱与快慢**：越强、范围越大，出手越慢。同一阶内每秒伤害大致持平，差异放在形状和状态上。
2. **升级**：只涨伤害（LV10 ×1.75）和起手/收势各最多 −0.05 秒；**范围不随等级涨**。个别招 LV3/LV7 强化状态、LV5 改形状。
3. **LV10 突破**（满级形状质变）：所有兵器最后统一做。
4. **范围**：招本身不大；想更大靠心法、道具（以后加"范围"类加成）。每招范围、速度在「武学试炼」里用拖动条调，复制给 Claude 写死。
5. **每种兵器 12 招**：黄 3 / 玄 4 / 地 3 / 天 2。
6. **黄阶可以只有形状、不带状态**（刀的黄阶已带状态，保留不改）；玄阶起带状态。
7. **速度、范围起点**（以调好的刀为标尺，新兵器先按此给，再用拖动条微调）：
   - 速度倍率：黄 ≈ ×1.3，玄 ≈ ×1.2–1.4，地 ≈ ×1.5–2.3，天 ≈ ×1.9–2.2
   - 范围倍率：黄 ≈ ×0.6–0.75，玄 ≈ ×0.55–0.75，地 ≈ ×0.33–0.8，天 ≈ ×0.75–1.1
8. **精锐 / 首领**：不被挑飞、不被眩晕（或减半），浮空易伤只吃一半，击退减半；破甲、流血等正常生效。
10. **受击（11/14 定，照群侠）**：普通命中敌人不停步、不硬直，只闪白、稍推一下（击退 ×0.35）；只有眩晕和浮空才让敌人停下。新兵器的控制全靠这两种状态。
11. **视觉分级（11/14 定）**：低阶武艺画面简单，高一阶稍好一点，只有天阶华丽。黄阶：一道干净的刀光，不带粒子；玄阶：稍亮、带一点残影；地阶：带颜色光晕和少量光点；天阶：独有的华丽特效（大光效、粒子、震屏）。图标、刀光、命中效果都照这个分级。
9. **说法**：起手 / 收势 / 出手快慢（极快 快 中 慢 极慢）/ 真气（护身 + 战后回血）/ 暴击 / 兵器精通 / 熟练 / 心法。不用 周天、发劲、护体、调息、会心、共鸣、连携。

## 状态池（全游戏 6 种，每种兵器主打 1–2 种，别的兵器可吃加成）
| 状态 | 效果 | 主打 |
|---|---|---|
| 破甲 | 每层受伤 +10%，最多 4 层，5 秒 | 刀、关刀、枪 |
| 流血 | 每 0.5 秒掉血，最多 5 层，4 秒；万刃归宗等可引爆 | 刀、剑、枪 |
| 浮空 | 挑飞，落地吃一下并晕 0.5 秒，1.8 秒内受伤 +25% | 刀、枪 |
| 眩晕 | 原地停住 | 锤、拳 |
| 迟缓 | 移速变慢 | 弓、石子、羽扇 |
| 灼烧 | 着火持续掉血，可扩散 | 黄符 |
